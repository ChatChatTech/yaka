# YaKa

YaKa 的公开产品工程仓库。不同交付物按顶层目录隔离，避免固件、应用和后续服务共享一套无法独立发布的构建与版本规则。

## 目录

| 目录 | 内容 | 当前状态 |
|---|---|---|
| [`firmware/`](firmware/) | YaKa 3.0 ESP32-C6 固件公开快照 | M1 / L0 软件基线 |
| `app/` | 后续软件应用 | 尚未建立 |

## 固件发布模型

固件在私有开发仓库中完成需求、硬件审计、开发和验证；达到可公开节点后，以经过审查的快照更新到 `firmware/`。公开仓库不合并私有 Git 历史，也不包含飞书登记、制造审计、供应链文件或未发布产品资料。

每次固件快照必须在 [`firmware/PUBLIC_RELEASE.md`](firmware/PUBLIC_RELEASE.md) 记录来源提交、上游基线、SDK、验证等级和排除范围。`firmware/` 的公开提交是发布记录，不是私有开发真值。

## 当前边界

当前版本只证明 ESP-IDF 6.1 下 YaKa 板型可以完成构建和静态合同测试。尚无公开的真实样机 L1/L2/L3 证据，因此不得把显示、音频、TF、NFC、IMU、电源或 OTA 描述为实板通过。

各目录的许可证以该目录内的 `LICENSE` 为准。
